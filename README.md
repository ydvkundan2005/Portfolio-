# Kundan Prasad Yadav — Portfolio

A responsive, single-page portfolio for Kundan Prasad Yadav, a B.Tech Computer Science and Engineering student at Aditya University (Class of 2027).

**Live site:** https://ydvkundan2005.github.io/Portfolio-  
**Repository:** https://github.com/ydvkundan2005/Portfolio-

## Design

The portfolio uses a restrained dark interface, clear typographic hierarchy, responsive project listings, accessible navigation, and a small amount of native JavaScript. It is built to load as a static site on GitHub Pages without a build step or third-party animation libraries.

## Sections

- **Introduction:** academic context, areas of interest, and résumé link.
- **About:** focus on Java, data structures and algorithms, and backend development.
- **Skills:** languages, backend, frontend, data, tools, and cloud/AI learning.
- **Projects:** Library Hub API System, Real-Time OTP System, SkillDzire Internship, and Deloitte Data Simulation.
- **Contact:** email, LinkedIn, GitHub, LeetCode, HackerRank, and CodeChef.

## Run locally

No package installation or build step is required. Open `index.html` in a browser, or start a local static server from this directory:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Contact form behavior

The contact form validates the required fields and opens the visitor's default mail application with a prefilled email. It does not send messages to a backend or store form submissions.

## Deployment

The site is static and can be deployed using GitHub Pages from the repository's configured publishing branch/workflow. There are no build artifacts to generate.
